TCG Collection Note v217 — iPhone実機テスト

1. 公開用ZIPを解凍し、中身をGitHubリポジトリ直下にアップロードしてください。ZIPそのものではなく、index.html、sw.js、manifest.webmanifest、アイコン等のファイルをアップロードします。
2. GitHub Pagesを main / root で公開し、生成されたURLをiPhoneのSafariで開きます。
3. 見た目：ネイビー背景、白い文字、シアンのアクセントが統一されているか。文字が小さすぎないか。
4. 操作：タイトル切替、カード検索、収録違い候補、所持登録、相場タブ、販売/買取の切替、店舗リンク、価格履歴、バックアップ/復元を確認します。
5. 画面が古い場合：Safariで再読み込み。PWAとしてホーム画面追加済みなら、タブを閉じて再度開き、必要なら一度閉じて起動し直します。
6. 気になる画面のスクリーンショットを撮り、送ってください。

注：価格検索リンクの存在は、店舗価格の自動取得を保証しません。価格表示の正確さと実機操作は、実際の公開環境で別途確認してください。
